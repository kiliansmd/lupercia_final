# Fonts for social previews

Local build assets, licensed under the included SIL Open Font Licenses. The preview generator makes no network requests and does not add these TTF files to the public website.

- Fraunces: Google Fonts `ofl/fraunces/Fraunces[SOFT,WONK,opsz,wght].ttf`, instantiated with fontTools at `opsz=36,wght=400,SOFT=0,WONK=1`.
- Source Sans 3: Google Fonts `ofl/sourcesans3/SourceSans3[wght].ttf`, instantiated at `wght=400`.

Source: https://github.com/google/fonts/tree/main/ofl (downloaded 2026-09-08).

Static TTF instances are included because Satori's font parser does not support the variable source fonts or the website's WOFF2 files.
